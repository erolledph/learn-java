## 2026-04-07 - Cache curriculum navigation indices
**Learning:** The application's global `state` in `app.js` tracked navigation context via `currentLesson` and `currentModule` but lacked their respective indices (`currentLessonIndex`, `currentModuleIndex`). This led to inefficient O(N) nested array lookups (e.g., `findIndex`) in `previousLesson`, `nextLesson`, and `updateNavigationButtons` across the entire `JAVA_CURRICULUM` on every navigation event.
**Action:** When tracking global state for nested list items, always cache their indices alongside the objects to enable O(1) state lookups and avoid redundant traversals.
## 2024-05-24 - Avoid redundant manual DOM manipulations for syntax highlighting
**Learning:** The application used a JavaScript function (`applySyntaxColors`) to manually manipulate the DOM for syntax highlighting on every keystroke (`state.editor.on('change', applySyntaxColors);`). This is a severe anti-pattern because the CodeMirror editor natively handles syntax highlighting and theming via CSS classes. The manual DOM manipulation causes layout thrashing and overrides CSS themes, negatively impacting typing performance.
**Action:** When using specialized libraries like CodeMirror, trust them to handle styling through CSS. Never use JavaScript loops to traverse and inject inline styles (`el.style.color = ...`) on elements that should be handled by an established CSS theme system.
## 2024-05-24 - Avoid synchronous layout thrashing in continuous drag events
**Learning:** The `mousemove` and `touchmove` events in the resizable panels (`initializeResizePanels`) were querying DOM layout properties like `getBoundingClientRect()` and `.offsetWidth` inside the `handleResize` callback on every pixel moved. This triggered synchronous reflows (layout thrashing) and resulted in poor resizing performance. Moreover, the events were not throttled.
**Action:** When handling high-frequency continuous events like dragging/resizing, always cache layout boundary properties on `mousedown` or `touchstart` instead of querying them during movement. Also, throttle updates using `requestAnimationFrame` so the browser renders layout changes smoothly without being bogged down by a clogged event queue.
